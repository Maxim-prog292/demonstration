# Логотипы в почтовых шаблонах

PNG-файлы подготовлены для совместимости с почтовыми клиентами и загружаются с домена проекта.

- `project-tver-emblem.png` — растровая копия уже используемого в проекте файла `public/assets/images/tver-oblast-emblem.svg`.
- `organizer-russia-my-history-cropped.png` — активная обрезанная версия знака Исторического парка «Россия — моя история» без пустых боковых полей.
- `organizer-russia-my-history.png` — прежний адрес файла, сохранённый для совместимости с уже отправленными письмами.
- `organizer-rvio.png` — официальный знак Российского военно-исторического общества: https://rvio.ru/og/og-logo.png
- `organizer-movement-first.png` — официальный знак Движения Первых: https://будьвдвижении.рф/local/templates/movement-first/icons/logo-red.svg

Источники проверены 2026-08-02. Перед публикацией владельцу проекта следует подтвердить у организаторов актуальную редакцию знаков и правила их взаимного размещения.
