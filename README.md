# Народное Вече - 2026 — GitHub Pages Demo

Откройте `index.html` через локальный веб-сервер или опубликуйте содержимое этой папки через GitHub Pages.

- сервер, база данных, SMTP и админка отсутствуют;
- 55 кандидатов встроены непосредственно в HTML;
- демонстрационный код показывается внутри формы;
- персональные данные никуда не отправляются.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий GitHub.
2. Загрузите **содержимое** этой папки в корень ветки `main`.
3. Откройте `Settings → Pages`, выберите `Deploy from a branch`, ветку `main` и каталог `/ (root)`.
4. Сохраните настройки и дождитесь ссылки на опубликованную страницу.

> В демонстрационной форме используйте только вымышленные данные: отправка намеренно выполняется локально в браузере.
