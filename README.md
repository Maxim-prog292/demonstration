# Народное Вече - 2026 — клиентская GitHub Pages-версия

Автономная статическая сборка второго этапа для публикации на GitHub Pages.

- сервер, база данных, SMTP и админка отсутствуют;
- 5 финалистов второго этапа встроены непосредственно в HTML;
- код подтверждения показывается в форме;
- персональные данные и сообщения не сохраняются;
- локально сохраняются только выбранные идентификаторы, время и номер демо-квитанции.

## Публикация на GitHub Pages

1. Загрузите содержимое папки в корень ветки `main`.
2. В `Settings → Pages` выберите `Deploy from a branch`, `main`, `/ (root)`.
3. Для проверки формы используйте только вымышленные данные.
