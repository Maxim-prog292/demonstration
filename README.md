# Демонстрационная версия для контент-менеджера

Статическая сборка проекта «Люди Тверской земли» для GitHub Pages.

## Особенности

- PHP, MySQL, SMTP, CAPTCHA, административная панель и серверная отправка голосов отсутствуют.
- Персоны, кандидаты, блоки и новости встроены непосредственно в HTML.
- JSON-файлы и сетевые запросы за контентом не используются.
- Выбор пяти кандидатов работает как локальная визуальная демонстрация и ничего не сохраняет.
- Все пути относительные, поэтому проект можно публиковать как GitHub Project Pages.

## Публикация

1. Создайте отдельный репозиторий GitHub.
2. Поместите содержимое этой папки в корень ветки `main`.
3. В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)`.
4. Дождитесь публикации GitHub Pages.

Файл `.nojekyll` уже добавлен. Сборка и зависимости не требуются.

## Обновление контента

Контент находится прямо в `index.html`, `news/index.html` и папках отдельных новостей. Исходный серверный проект содержит генератор `scripts/build-content-manager-demo.php`, который может пересобрать эту папку из редакционной базы.

Важно: это демонстрация. Для рабочего голосования необходима серверная версия проекта.
